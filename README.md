# АИС автотранспортного предприятия

Десктоп-приложение для учёта работы автотранспортного предприятия: автопарк, водители, сотрудники, клиенты, заявки, рейсы, ремонты и техосмотры. Курсовой проект (МИ ВлГУ, направление «Программная инженерия»).

## Возможности

- **Справочники и учёт.** Автомобили и их состояние, водители, сотрудники и должности, клиенты, адреса, заявки клиентов, рейсы, ремонты, технические осмотры.
- **CRUD для каждой сущности.** Добавление, редактирование и удаление записей через отдельные формы.
- **Рейсы.** Учёт рейсов и отметка о завершении рейса.
- **Поиск** по таблицам главного окна.
- **Отчёты:** расход топлива и работа водителей.
- **Локализация интерфейса:** русский, английский, немецкий.
- **Вход в БД** через диалог: логин и пароль не хранятся в коде.
- **Проверка ввода:** кнопка «Сохранить» недоступна, пока форма заполнена не полностью.

## Архитектура

```
src/main/java/ru/kpr/kyrs/
├── MainApplication.java      # точка входа
├── Controllers/              # контроллеры FXML-форм (главное окно + 9 форм)
├── Dao/
│   ├── Interfaces/           # интерфейсы доступа к данным (CarDaoInt, TripDaoInt, ...)
│   └── Classes/              # реализации на JDBC
├── Pogo/                     # модели данных (Car, Driver, Trip, ...)
└── Utilites/                 # подключение к БД, вход, смена языка
src/main/resources/ru/kpr/kyrs/
├── *.fxml                    # разметка окон
├── messages*.properties      # тексты интерфейса (ru / en / de)
└── config.properties         # адрес и схема БД
```

- **MVC:** окна описаны в FXML, логика вынесена в контроллеры.
- **DAO-слой:** контроллеры работают с интерфейсами, а не с SQL напрямую. Это упрощает замену хранилища и тестирование.
- **Модуль Java** (`module-info.java`): пакеты открыты только тем модулям JavaFX, которым они нужны.

Схема `scheme1`, 11 таблиц: `cars`, `car_conditions`, `drivers`, `works`, `worker_types`, `clients`, `addresses`, `client_requests`, `trips`, `repairs`, `technical_inspections`.

## Запуск

**Нужно:** JDK 17+, Maven, PostgreSQL.

1. Создать базу `ais_tp` и выполнить скрипты:
   ```bash
   psql -U postgres -c "CREATE DATABASE ais_tp;"
   psql -U postgres -d ais_tp -f ais_tp.sql
   psql -U postgres -d ais_tp -f заполнение_тест.sql
   ```
2. При необходимости поправить адрес сервера в `src/main/resources/ru/kpr/kyrs/config.properties` (по умолчанию `localhost:5432`).
3. Запустить:
   ```bash
   mvn clean javafx:run
   ```
4. В окне входа ввести логин и пароль пользователя PostgreSQL.

## Тесты

UI-тесты на TestFX: добавление клиента и заявки, блокировка кнопки сохранения при неполной форме.

```bash
mvn test
```
